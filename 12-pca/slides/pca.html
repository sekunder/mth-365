Principal Component Analysis (PCA): Why?

Sometimes a data set has a lot of variables.

  • Some of these variables carry lots of information.
  • Others carry little to no information.

PCA can help reduce the dimensionality of data by summarizing most of the variation into fewer dimensions, called components.

Don’t Panic But It’s Time For Linear Algebra

Outlining the idea

  • Our data has \(p\) features, \(X_1,\dots,X_p\)
  • A linear combination of features is a new variable \(Z = \phi_1X_1 + \phi_2X_2 + \cdots + \phi_pX_p\) (each \(\phi_j\) is just a number)
  • Notice that \(Z\) is a new numerical variable, so we can compute its variance. Different choice of \(\phi_j\)s will give different variance
  • Key idea: we can find \(\phi_j\)s (under some constraints) to maximize variance of \(Z\)
    • that is the first principal component

PCA: How? (2/3)

  1. Find Principal Components. Features are \(X_1, \dots X_p\).
  • First Principal Component: \(Z_1 = \phi_{11}X_1 + \phi_{21}X_2 + \cdots + \phi_{p1}X_p\)
    • Choose \(\phi_{j1}\)s to maximize variance of \(Z_1\)
    • Normalized: \(\sum^p_{j=1} \phi^2_{j1} = 1\)
    • optimization problem: \(\text{maximize}_{\phi_{11}, \dots \phi_{p1}}(\frac{1}{n}\sum^{n}_{i=1}(\sum^{p}_{j=1}\phi_{j1}x_{ij})^2)\)
    • the \(\phi_{jk}\)s are called loadings

  • Second Principal Component: maximal variance out of all linear combinations that are uncorrelated (that is, orthogonal) with \(Z_1\)

  • \(k\)th principal component maximizes variance while orthogonal to first \(k-1\) components.
